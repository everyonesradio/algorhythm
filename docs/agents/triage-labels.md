# Triage labels

Canonical role → GitHub label (defaults):

| Role | Label |
|------|-------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

Create these labels in the repo if they don't exist yet
(`gh label create …`). `/triage` depends on them.
